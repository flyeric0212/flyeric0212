## 🧩 Open Source

### [cursor-rules](https://github.com/flyeric0212/cursor-rules)

整理和维护不同技术栈的 Cursor Rules，让 AI Coding 在真实项目中拥有更稳定的工程约束。

### [agent-skills](https://github.com/flyeric0212/agent-skills)

面向 Codex、Claude Code、Cursor、OpenCode 等 Coding Agent 的实用 Skills 集合，沉淀可重复使用的工程工作流。

### [pi-packages](https://github.com/flyeric0212/pi-packages)

基于 Pi 原生 API 构建的模块化扩展集合，包括 TUI、权限守护与其他轻量工具。

### [cursor-history-links](https://github.com/flyeric0212/cursor-history-links)

自动维护 Cursor 在 Windows、macOS 与 Linux 平台上的历史版本下载地址。
